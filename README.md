# Arogya - Nepal's Herbal Collection

![Arogya Banner](public/img/thumbnail.svg)

#[Live Preview](https://arogyaa.vercel.app/)
## Overview

Arogya is a comprehensive web application dedicated to documenting and showcasing the rich herbal heritage of Nepal. It provides detailed information about various medicinal herbs found across different ecological regions of Nepal, highlighting their traditional uses, medicinal properties, scientific research, and cultural significance.

## Features

### 🌿 Extensive Herb Database
- Detailed profiles of medicinal herbs native to Nepal
- Scientific names and classifications
- High-quality images for identification

### 🗺️ Interactive Regional Mapping
- Visual representation of herb distribution across Nepal's ecological zones
- Interactive Nepal map showing where specific herbs can be found
- Region-specific herb filtering

### 🔍 Comprehensive Herb Information
- Medicinal properties and traditional uses
- Scientific research and chemical compounds
- Cultural significance and historical context
- Sustainability practices and ecological status

### 🌐 Bilingual Support
- Full content available in both English and Nepali
- Easy language switching throughout the application

### 📱 Responsive Design
- Optimized for all devices from mobile phones to desktop computers
- Accessible interface with intuitive navigation

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Routing**: React Router
- **UI Components**: Custom components with shadcn/ui
- **Icons**: Lucide React
- **Map Visualization**: Custom SVG mapping solution
- **Internationalization**: Custom language provider

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dhunganapradip/arogya.git
   cd arogya
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

### Exploring Herbs
- Browse the herb collection from the homepage
- Use filters to find herbs by ecological region, medicinal properties, or uses
- Click on any herb to view its detailed profile

### Understanding Herb Details
- **Overview**: General information, distribution, and lifecycle
- **Medicinal**: Therapeutic properties, traditional uses, and preparation methods
- **Scientific**: Modern research, chemical compounds, and nutritional value
- **Cultural**: Cultural significance, ecological status, and sustainability practices

### Using the Interactive Map
- View distribution of herbs across Nepal's ecological regions
- Highlight specific regions to see which herbs grow there
- Navigate between ecological zones to understand herb diversity
